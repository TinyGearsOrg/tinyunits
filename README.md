# uom

A Java library for typed quantities and units of measurement, implementing JSR-385 (`javax.measure`, unit-api 2.2). It is in development.

Status: milestone 1 (core units, exact conversion factors, `.units` definition parser). Not released.

See [docs/REQUIREMENTS.md](docs/REQUIREMENTS.md) and [docs/DESIGN.md](docs/DESIGN.md).

## Generated quantity sources

The sources in `uom-quantities/src/main/java/org/tinygears/uom/quantity` are generated by `uom-codegen` from `data/quantity-types.txt` and `data/base.units`, and are committed. After changing `data/`, regenerate from the repository root:

    mvn -q -B -Pgenerate -pl uom-codegen -am process-classes

`GeneratedSourcesUpToDateTest` fails when `data/` and the committed sources disagree.
